# 고객 더미데이터 분류·정렬 분석

`customer_data.csv`의 고객 1,000행을 연령대, 흡연 여부, 결혼 여부, 자녀 수, 가입 상품, 가입 특약으로 분류한 자료입니다. 작성일은 2026-09-18이며 원본 데이터의 기준일과 가입일은 제공되지 않았습니다.

## 결과 파일

- [고객 분류 분석 엑셀](./동양생명_고객분류분석.xlsx): 분석요약, 항목별집계, 상품교차분석, 특약교차분석, 고객데이터, 분류기준의 6개 시트입니다.
- [항목별 정렬 CSV 압축파일](./동양생명_항목별정렬_CSV.zip): 6가지 기준별 정렬 CSV, 항목별 집계 CSV, 사용 설명이 들어 있습니다. 한글 호환을 위해 UTF-8 BOM으로 저장했습니다.

엑셀의 `고객데이터` 시트에서 머리글 필터로 여러 조건을 함께 선택하거나 정렬할 수 있습니다. 집계 시트는 필터 적용 여부와 관계없이 전체 1,000행을 기준으로 계산합니다. 행을 추가하려면 수식 참조 범위를 확장해야 합니다.

## 주요 집계

| 기준 | 고객수 |
| --- | --- |
| 연령대 | 20대 220명, 30대 202명, 40대 235명, 50대 234명, 60~65세 109명 |
| 흡연 여부 | 비흡연 766명, 흡연 234명 |
| 결혼 여부 | 미혼 337명, 기혼 663명 |
| 자녀 수 | 0명 487명, 1명 295명, 2명 207명, 3명 11명 |
| 가입 상품 | 암/건강 330명, 간편심사 261명, 종신 202명, 연금 207명 |
| 특약 상태 | 가입 650명, 선택 안함 143명, 상품에 특약 없음 207명 |

특약 가입률은 전체 고객 기준 65.0%입니다. 생성 코드상 특약이 없는 연금상품을 제외하면 793명 중 650명인 82.0%입니다. `선택 안함`과 `특약 없음`을 구분해 집계했습니다.

## 분류 기준과 해석

- 원본 11개 항목을 보존하고 분석ID, 연령대, 자녀구간, 상품분류, 특약상태, 특약가입여부를 추가했습니다. 분석ID는 원본 행 순서에 따라 부여한 임시 식별자입니다.
- 60대는 실제 관측 범위인 60~65세입니다. 자녀구간의 `3명 이상`은 이번 원본에서는 모두 3명입니다.
- 정렬 CSV 6개는 같은 고객 1,000행의 순서만 다릅니다. 서로 합산하지 않습니다.
- 원본 값이 모두 같은 중복 15행은 생성 표본으로 보존했습니다. 원본 고객ID가 없어 동일인인지 판단할 수 없습니다.
- PDF의 `질병 및 재해 수술비 특약`과 CSV의 `수술비 보장 특약`은 문맥상 대응하는 것으로 해석했으며, CSV 원문을 바꾸지 않았습니다.
- 생성 코드가 나이·가족관계·질환 등에 따라 상품과 특약의 선택 확률을 설정합니다. 이 결과는 실제 고객 선호, 인과관계 또는 개인별 가입 권고를 뜻하지 않습니다.
- 가입일·보험료·가입금액·복수계약 정보가 없어 시계열, 매출, 보장 적정성은 분석하지 않았습니다.
