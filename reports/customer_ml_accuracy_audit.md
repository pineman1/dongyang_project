# 고객 상품 추천 정확도 점검 (목업 데이터)

이 문서는 **서로 다른 두 정답**을 분리합니다. 기존 `가입상품`은 `generate_data.py`가 확률적으로 뽑은 상품이며, 새 `목업_적합상품`은 아래에 공개한 보장·예산 규칙의 결과입니다. 두 정확도를 이어 붙여 성능 향상으로 해석할 수 없습니다. 웹 화면과 기존 추천 함수는 이 실험 때문에 바꾸지 않았습니다.

## 기존 가입상품 예측

- 원본: `customer_data.csv` 5,000건. `generate_data.py`를 별도 폴더에서 다시 실행해 생성한 CSV의 SHA-256이 원본과 동일함을 확인했습니다 (`6180a2e8b167dc68a99c88de3f724fef25082325970b73ce0f819b8a693f96b9`).
- 고객의 원래 9개 조건 조합을 그룹으로 묶어 학습 3,986건과 검증 1,014건으로 분리했습니다. 동일 조건 조합의 양쪽 중복은 0건입니다.
- 현재 RandomForest의 주계약 1순위: 585/1,014 = **57.7%**. 정답이 1·2순위 중 하나에 포함: 826/1,014 = **81.5%**. 고객별 결과는 `customer_ml_holdout_predictions.csv`에 있습니다.
- 동일 조건 조합인데 가입상품이 다른 그룹이 292개(해당 행 700건)입니다. 생성 코드에서 상품을 `np.random.choice(products, p=probs)`로 뽑기 때문입니다.
- 원본 생성 규칙의 네 상품 확률을 그대로 재구성하면, 각 행에서 가장 높은 확률을 고르는 **이론상 기대 일치율**은 전체 5,000건 평균 약 **55.2%**입니다. 한 번 뽑힌 유한 검증 표본의 실측 정확도는 이 기대값보다 높거나 낮을 수 있습니다. 이 값은 실제 고객 적합도의 상한이 아닙니다.
- 9개 조건 그룹을 유지한 5분할 비교에서 기존 RandomForest 1순위 평균은 **55.6%**, 생성 규칙의 위험·생애주기 변수로 묶은 RandomForest는 **55.8%**, 같은 변수를 사용한 로지스틱 회귀는 **56.0%**였습니다. 개별 검증 분할에서는 묶은 변수 모델이 57.7%에서 58.1%로 올랐지만, 5분할 평균 차이는 작아 모델 교체를 정당화할 만한 안정적인 개선으로 보지 않았습니다.

## 별도 목업 적합성 실험

`customer_ml/mock_suitability.py`는 기존 9개 조건에 **우선 보장 목표, 추가 보장 목표, 월 예산 구간**을 더해 별도의 시나리오 5,000건을 만듭니다. 암·건강, 유병자 보장, 가족 생활비, 노후 자금의 필요 점수를 계산하고, 예산을 넘는 상품을 후보에서 제외합니다. 기본 모의 월비용은 각 상품에 대해 7만·9만·13만·11만 원으로 **임의 설정**한 값이며, 나이·흡연·만성질환에 따라 모의 가산을 합니다. 이는 실제 보험료나 가입 가능 여부가 아닙니다. 필요 점수 4점 이상의 상품이 없으면 `예산·보장 재검토`로 보류합니다.

전체 목업 시나리오 5,000건은 `data/mock_suitability_customers.csv`에 저장합니다. 기존 CSV의 고객 조건을 재사용한 데이터이므로 독립적으로 수집한 고객 5,000명이 아닙니다.

목업 목표 생성과 적합 상품 규칙은 모두 공개되어 있으며, 기존 `가입상품`·`가입특약` 열은 새 모델의 입력이나 정답으로 사용하지 않습니다. 원래 9개 조건 조합 단위로 학습·검증을 분리하고, 학습 데이터 내부에서 RandomForest와 HistGradientBoosting을 비교해 후자를 선택했습니다.

| 목업 정책 재현 지표 | 결과 |
|---|---:|
| 모델 단독 1순위 분류 | **1,012건 (99.8%)** |
| 별도 검증 1,014건 중 정책 정답과 일치 | **1,013건 (99.9%)** |
| 상품을 제시한 비율 | **553건 (54.5%)** |
| 예산·보장 조건을 만족하는 두 후보를 제시할 수 있는 비율 | **231건 (22.8%)** |
| `예산·보장 재검토`로 보류한 비율 | **461건 (45.5%)** |
| 모의 예산을 초과한 상품 제시 | **0건** |

99.9%는 **사람이 독립적으로 판정한 고객 적합도**가 아니라, 모델이 **우리가 만든 결정 규칙을 재현한 비율**입니다. 기존 가입상품 정확도 57.7%가 99.9%로 개선된 것이 아닙니다. 특히 현재 임의 비용 가정에서는 고객의 45.5%에 추천을 보류하므로 이 목업을 실제 상담용으로 사용해서는 안 됩니다. 이 결과와 검증 행은 각각 `mock_suitability_metrics.json`, `mock_suitability_holdout.csv`에서 확인할 수 있습니다.

코드 호출은 1순위에 학습 모델의 상품 예측을 사용하고, 목업 보장 점수 4점 미만이거나 예산을 넘는 상품을 차단합니다. 그래서 모델 단독 99.8%와 가드 적용 후 99.9%를 구분합니다. 2순위가 있는 경우에는 공개된 목업 보장·예산 점수로 비교 후보를 고릅니다. 상품에 맞는 특약은 별도 목업 규칙으로 정하고, 반환하는 `모의_월부담_만원`에 특약의 임의 추가 비용 0~2만 원을 포함합니다. **99.9%는 1순위 상품에 대한 수치이며 2순위의 유용성이나 특약의 실제 적합도 수치가 아닙니다.** 조건을 충족하는 두 번째 상품이 없으면 2순위를 채우지 않습니다.

독립 검토를 위해 `mock_suitability_review_template.csv`에 검증 고객 100건을 목업 정책 결과별로 20건씩 뽑았습니다. 이 파일에는 정책 정답과 모델 예측을 넣지 않았습니다. `목업비용_1~4_만원`은 위 표의 상품 순서대로 계산된 **임의 비용**입니다. 검토자가 `검토_적합상품`과 `검토_근거`를 채운 뒤에야 사람의 판단과 모델 결과를 별도로 비교할 수 있습니다.

## 권장 결정

1. 목업 시연에는 설명 가능한 **보장·예산 규칙 자체**를 사용하고, 모델의 99.9%를 실사용 성능으로 홍보하지 않습니다. 학습 모델은 규칙을 흉내 내는 실험 결과로만 둡니다.
2. 독립 평가가 필요하면 상담 담당자가 원본 가입상품을 보지 않고 목업 사례의 적합 상품과 보류 여부를 판정하도록 합니다. 최소한 모호하거나 예산 경계에 있는 사례를 포함해야 합니다.
3. 상품별 실제 보험료·가입 조건이 확보되기 전에는 비용 가정을 `모의`로 표시하고, 고객 월 예산에 대한 실제 적합성은 평가하지 않습니다.
