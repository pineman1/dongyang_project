# 보험료 데이터 출처

## 사용한 자료

- 작성 기관: 동양생명, BA본부 제작(2023년 8월)
- 공개 호스팅: 하나은행
- 상품: 무배당엔젤안심보험, **2023년 9월 개정**
- 원문: https://image.kebhana.com/cont/download/insdocument/leaflet/L74B14160_lf.pdf
- 보험료 표 위치: PDF **3쪽**, 인쇄 **4~5쪽**
- 확인일: 2026-09-17
- 데이터 성격: 보험사가 공개한 가입 조건별 **보험료 예시**, 개인 계약/청구 기록 아님
- 총 72개: 보장 유형 2 × 환급 유형 2 × 성별 2 × 연령 3 × 납입기간 3
- 합성 또는 보간으로 늘린 학습 행: 0개

원문 페이지를 이미지로 확인해 표의 열과 숫자, 각 표 위의 기준을 대조했습니다. PyMuPDF로 네 개 보험료 표를 추출하며, 환급금 예시표나 가입 가능 나이 표는 학습에 넣지 않습니다. 실제 상품 가입 가능 나이와 이번 데이터의 관측 나이는 다릅니다.

`premium_source.json`은 URL, PDF와 CSV의 SHA-256, 상품 버전, 페이지, 추출 시각을 기록합니다. 수집 스크립트는 PDF의 해시가 달라지면 중단하므로 개정된 표를 기존 버전으로 잘못 읽지 않습니다. 원본 PDF 자체는 저장소에 재배포하지 않습니다. Git의 줄바꿈 변환으로 CSV 해시가 바뀌지 않도록 `.gitattributes`를 설정했습니다.

## 열 정의

| 열 | 의미 |
| --- | --- |
| record_id | 이 스냅샷 내 유일한 행 ID |
| product_name / product_version | 상품명 / 개정 월 |
| age / sex | 표의 가입 보험나이 / 남자·여자 |
| coverage_type | 치매보장형 / 생활비보장형(장해) |
| refund_type | 표준형 / 해약환급금일부지급형 |
| payment_years | 보험료를 납입하는 기간(년) |
| sum_assured_krw | 주계약 보험가입금액, 10,000,000원 고정 |
| coverage_end_age | 보험 만기 나이, 110세 고정 |
| payment_frequency | monthly, 월납 고정 |
| monthly_premium_krw | 목표값: 월 보험료, 원 단위 |
| source_id / source_pdf_page | 출처 ID / 1부터 시작하는 PDF 페이지 |

목표값·출처 ID·문서 버전·행 ID는 회귀 입력에 사용하지 않습니다. 고정 가입금액을 변수로 학습했다고 주장하지 않으며 다른 가입금액으로 비례 환산하지 않습니다.
